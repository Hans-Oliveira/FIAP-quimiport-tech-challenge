# FIAP-quimiport-tech-challenge
Tech Challenge é o projeto que engloba os conhecimentos obtidos em todas as disciplinas da fase. Esta é uma atividade que, a princípio, deve ser desenvolvida em grupo. É importante atentar-se ao prazo de entrega, pois se trata de uma atividade obrigatória, valendo 90% da nota de todas as disciplinas da fase.
